@ARTICLE Number Sets
# Natural numbers N
  1, 2, 3, ...  (sometimes from 0)

# Whole numbers
  0, 1, 2, 3, ...

# Integers Z
  ..., -2, -1, 0, 1, 2, ...

# Rational numbers Q
Any ratio a/b of integers with b not 0.
Decimals terminate or repeat.

# Irrational numbers
Cannot be written as a fraction. Their
decimals go on forever without a
pattern: pi, e, sqrt(2).

# Real numbers R
All rationals plus all irrationals.

# Complex numbers C
  a + bi, where i^2 = -1
Every real number is complex with b = 0.

# Nesting
  N in Z in Q in R in C

@ARTICLE About This App
MATHWIKI is an offline math reference
for the TI-84 Plus CE Python, written in
C with the CE toolchain.

# Controls
  UP / DOWN     move the selection
  LEFT / RIGHT  page up / page down
  2ND or ENTER  open the selection
  CLEAR or DEL  go back
  Y=            search all articles
  ZOOM          list every article
  MODE          quit to the OS

In any list, pressing a letter key jumps
to the first entry starting with it.

# In an article
  UP / DOWN     scroll one line
  LEFT / RIGHT  scroll one screen
  WINDOW        jump to the top
  GRAPH         jump to the end
  TRACE         next article
  CLEAR or DEL  back to the list

# In search
Type letters with the ordinary ALPHA
key labels (no need to press ALPHA).
  DEL     backspace
  0       space
  CLEAR   exit search
Matching is case insensitive and looks
anywhere inside a title.

# Adding your own articles
Edit the plain text files in content/,
run the build, and send the new .8xp
back to the calculator. The format is
documented in the project README.
